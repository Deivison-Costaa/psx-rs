# 0004 — CI e proteção de branch

- **Data:** 2026-07-27
- **Item do roadmap:** 0.4
- **Objetivo:** CI que mede sempre (sem condicionais) e formato de commit blindado.

## O que foi feito

`ci.yml`: job `check` (fmt → clippy `-D warnings` → `cargo test --all`) em ubuntu-latest com
as libs que o `psx-desktop` vai exigir (alsa/udev/xkbcommon) — core+cli+desktop compilam no
Linux em todo PR (requisito multiplataforma). `commit-lint.yml` em workflow separado (evita
condicional): valida título `iter NNNN: ... (ROADMAP X.Y)` e prefixos
`test|feat|fix|refactor|docs|chore(escopo):` nos commits não-merge do PR.

Após CI verde: proteção da `main` via API — PR obrigatório, checks `check` + `commit-lint`,
`enforce_admins`, force-push e deleção bloqueados.
